# Bonos de ventas

Leer también [AGENTS raíz](../AGENTS.md) y las
[protecciones compartidas de bonos](../bonos_produccion/AGENTS.md).
Aplican a `bono_extra`, `ajuste_positivo` y `ajuste_negativo` de ventas:
`recalcular()` y `recalcular_todos()` nunca sobrescriben capturas manuales.
Para verificar ventas, consultar sus modelos/tablas reales; el SQL de producción
es un ejemplo de producción y no acredita registros de ventas.
